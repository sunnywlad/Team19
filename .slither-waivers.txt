# Format, une alerte par ligne :
#   DETECTEUR | fichier:fonction | raison | AAAA-MM-JJ
#
#   DETECTEUR : nom du détecteur slither (weak-prng, arbitrary-send-eth, ...)

#   date      : dernier jour de validité. Passé ce jour, le contrôle échoue
#               tant que la ligne n'est pas retirée ou le code corrigé.
#
# Une ligne mal formée fait aussi échouer le contrôle. Une ligne qui ne
# correspond plus à aucune alerte est signalée : la retirer.
