Les huit icônes de couche de Veto : agent, porte d'entrée, signature, relais, contrat, humain, quarantaine, journal.

Grille 24 px, trait de 1,75 px, extrémités et jonctions arrondies, aucun aplat. Encre unique `#1e1730` (valeur de `texte` en clair) : une image `<img>` n'hérite pas de `currentColor`, donc sur le thème sombre ces fichiers se posent sur une surface claire, ou on incorpore le SVG en ligne avec `stroke: currentColor`. Les glyphes de décision (croix, sablier, coche) vivent dans les composants, pas ici.
