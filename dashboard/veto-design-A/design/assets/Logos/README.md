- `veto-logo.jpg` : le logo complet avec le mot Veto, fourni par l'équipe, sur fond blanc. À poser sur une surface claire seulement.

Ne pas redessiner le logo : en cas de besoin d'une version sur fond sombre, demander le fichier original.
