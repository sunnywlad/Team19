L'écran d'incidents sert l'analyste sécurité : les incidents ouverts, l'agent concerné, les faits bruts, le rapport.

**Fournir** : la liste d'incidents du service de réponse, le rapport du plus récent, et le journal de ses réactions.

- La liste à gauche, le rapport à droite. Un incident sélectionné prend `accent-fond`.
- Le rapport commence par l'issue en mots (« arrêtée à la porte ») et une phrase simple. Il dit ce qui n'a pas bougé : « Aucun fonds n'a bougé ».
- Lever une pause se fait par un humain, hors dashboard : l'écran le montre comme une force.
- Un export PDF d'une page reprend les mêmes signes (voir `RapportIncident`).
