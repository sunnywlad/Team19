L'état d'erreur dit qu'une lecture a échoué et que, dans le doute, rien ne part.

**Fournir** : les sources injoignables et le délai écoulé. Les valeurs périmées restent visibles mais grisées (`perime`).

- Ovale plein en `refuse-signal`, glyphe de clé barrée, titre factuel, phrase « Rien n'est autorisé par défaut ».
- Une panne ou un délai dépassé vaut refus, jamais autorisation : l'écran le dit au lieu de l'impliquer.
- Le bouton relit seulement (GET). Aucune action ne paie, ne met en pause ni n'approuve depuis ce tableau.
- `role="alert"` pour être annoncé par les lecteurs d'écran.
