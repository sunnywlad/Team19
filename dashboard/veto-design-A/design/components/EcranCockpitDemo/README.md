Le cockpit en mode démo : même écran, branché sur le faux coffre en mémoire.

- Un bandeau permanent dit « COFFRE SIMULÉ : aucun fonds, aucune chaîne », et les panneaux alimentés par le faux coffre portent « simulation ».
- Ce mode ne s'affiche que si le proxy local annonce `fake`. Sans l'annonce, les panneaux portent « origine non confirmée » : jamais « réel » par défaut.
- À utiliser pour les démonstrations, pas pour un client en production.
