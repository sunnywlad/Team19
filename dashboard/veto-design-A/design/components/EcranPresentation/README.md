La page de présentation publique porte la proposition de valeur : plusieurs gardiens, un seul veto suffit.

**Fournir** : le parcours d'une demande, les chiffres autorisés avec leur condition, et la phrase de fond.

- Elle commence par la promesse et la table ronde, pas par un tableau de bord.
- Chaque chiffre porte sa condition dans la phrase d'à côté. Formulations interdites : « protégé contre l'injection », « zéro attaque réussie », « conforme », « certifié », « détecte les zero-days », « le contrat paie » sans « sur réseau de test ».
- « Argent Intelligent » n'apparaît qu'en sous-titre, jamais comme marque principale.
- Chaque ligne du parcours a son icône de couche (agent, porte, signature, contrat, humain, journal) : un seul trait, une seule épaisseur.
