La barre de trésorerie rend la formule évidente : cash = dettes admises + réserve + placements bloqués + plaçable.

**Fournir** : les quatre termes tels que la vue du contrat les renvoie, et le cash. Un terme illisible : « Non mesuré », pas de barre.

- La formule s'écrit au-dessus, terme par terme, avec le même ordre que la barre. L'œil lit l'addition avant de lire la barre.
- Chaque segment a une forme en plus d'une couleur : plein violet (dettes), hachures grises (réserve), plein moutarde (bloqué), plein sarcelle (plaçable). Deux pixels de `surface` les séparent.
- La largeur d'un segment est sa part du total. Aucun terme n'est recalculé. Si la somme diffère du cash, la barre est tracée à l'échelle de la somme et un message le dit.
- Une facture bloquée reste une dette admise : « montant bloqué » n'est pas un cinquième terme.
- Un segment à 0 reste dans la légende, avec son 0 : l'argent qui ne bouge pas est aussi un fait.
