L'écran de connexion ouvre l'accès en lecture seule. Il fait une chose : envoyer vers l'identité de l'entreprise.

**Fournir** : le fournisseur d'identité de l'entreprise (SSO), les messages d'erreur d'accès, le contact de l'administrateur.

- Un seul bouton : l'identité de l'entreprise (SSO). Pas de formulaire de mot de passe à concevoir ni à protéger ici, pas de création de compte, pas d'écran de profil.
- La phrase « Accès en lecture seule : ce compte ne peut ni payer, ni approuver, ni lever une pause » est visible dès la connexion. Un compte Veto n'est pas une clé.
- Accès refusé : on le dit en mots, avec l'icône, et on précise qu'aucune donnée n'a été chargée.
- Session expirée : retour à cet écran, puis à la page demandée.
- Les rôles s'affichent en lecture seule dans la page « Rôles ». Ils se règlent dans l'annuaire de l'entreprise, pas dans Veto.
